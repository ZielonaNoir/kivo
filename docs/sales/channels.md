# 销售渠道总览

更新与公开资料核查日期：2026-10-08（Asia/Hong_Kong）。

Kivo（起形）拟提供“参考图片 → 3D 资产 → Blender / Unreal Engine 工作流”的工具能力，通过 API / MCP 按量调用。当前仓库只有项目说明与规划文档，接口、计费与可交付质量尚未验证。视频制作团队可作为资产工具的客户，成片制作暂不作为核心交付。

本表覆盖当前讨论中的渠道和首轮值得验证的扩展渠道。优先级为项目建议：P0 首轮验证；P1 第二轮；P2 储备。接入成功、商店上架、平台推荐和付费转化分别记录，不互相替代。所有渠道目前均未联系、未入驻、未达成合作。

## 首轮执行顺序

1. 联系 C03 的真实使用者，选出一个有参考图、验收规范和预算的试用场景。
2. 准备可运行的单图道具 Demo、MCP 接入和报价，再对接 C01、C02。
3. 同步验证 C04 的插件发布可行性；单独核实 C05，避免把扣子上架当作豆包上架。
4. 有合格成品资产后再测试 C08–C10；C06、C11 先走自助安装获客。

这只是任务顺序；外联是否开始、试用是否通过，以联系台账和实际证据为准。

## 商业模式与指标

- API / MCP：按成功交付的任务计费为拟议方案；失败、重试、退款规则待成本测试后确定。
- 工作室：预付额度或团队包为候选方案，先确认交付规格和人工修复成本。
- 资产平台：销售可下载资产包或插件，收入与按量 API 分开统计。
- 合作分发：推荐位、联合案例、渠道分成均须获得书面确认；未确认前不做收入预测。

按渠道记录有效线索数、试用人数、交付成功率、首单转化、收入、渠道费用、合格资产成本和复购。避免把安装数当成付费客户数。

## 维护规则

新增渠道分配稳定 ID，同步补充 contacts.md。每次核查记录日期与官方链接；未找到的入口写“待核实”，不猜测邮箱或负责人。沟通回复只记录事实和证据，未获回复不升级状态。每次正式对接前重新核查联系人与政策。私有仓库也不存 API Key、身份证、营业执照扫描件或合同敏感附件。
